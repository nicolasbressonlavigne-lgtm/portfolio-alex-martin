# Portfolio — Alex Martin

Page de présentation d'un **profil fictif**, créée pour un exercice.

- Poste recherché : préparation de commandes, en logistique.
- Zone : Lyon et 20 km alentour.
- Aucune donnée personnelle réelle, aucun formulaire, aucune collecte.

## Contenu

| Fichier | Rôle |
| --- | --- |
| `index.html` | La page et ses textes |
| `style.css` | Mise en forme, illustration d'en-tête, adaptation au téléphone |
| `script.js` | Ouverture et fermeture des détails de la réalisation |
| `entrepot.svg` | Illustration fictive de l'en-tête |

## Voir la page

Le site est publié via GitHub Pages : https://nicolasbressonlavigne-lgtm.github.io/portfolio-alex-martin/

En local, il suffit d'ouvrir `index.html` dans un navigateur : aucune installation,
aucune bibliothèque, aucun service payant.
